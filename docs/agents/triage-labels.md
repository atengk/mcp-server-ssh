# Issue 分流标签映射规范

工程技能基于五种标准分流角色开展工作。本文件将这五种标准角色映射至本项目 GitHub 跟踪器中的实际标签名称：

| 技能标准标签角色 | 仓库实际标签 | 语义与职责 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 待维护者/负责人初审评估优先级与分类 |
| `needs-info` | `needs-info` | 关键背景或复现步骤不足，挂起等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格与验收条件已完备，可供脱机 AI Agent 自主实现 |
| `ready-for-human` | `ready-for-human` | 涉及重要决策或外部受限资源，需人类开发者手动实现 |
| `wontfix` | `wontfix` | 经评估不予采纳、不予处理或超出范围关闭 |

当技能提及某类角色动作时（例如“打上脱机就绪标签”），自动使用本表中对应的标签值。
